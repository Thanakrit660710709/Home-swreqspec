# Feature: ค้นหาและเปรียบเทียบหอพัก (Search and Compare Dormitories)
Spec ID: SPEC-SCD-001 |  Use case: UC-01
Owner: Home | Status: Draft v1 | Updated: 2569-09-09

## Goal
ระบบช่วยให้นักศึกษาและผู้ปกครองสามารถค้นหาหอพักตามเงื่อนไขที่กำหนด (เช่น งบประมาณ, ระยะทาง, สิ่งอำนวยความสะดวก) และเลือกหอพักที่สนใจมาแสดงผลเปรียบเทียบแบบเคียงข้างกัน (Side-by-Side) ได้

## Scope
### In scope
- ค้นหาหอพักตามช่วงราคาค่าเช่า
- ค้นหาหอพักตามระยะทางจากสถานศึกษา
- ค้นหาหอพักตามสิ่งอำนวยความสะดวก เช่น แอร์ ลิฟต์ และที่จอดรถ
- ค้นหาตามนโยบายการเลี้ยงสัตว์
- แสดงสถานะห้องว่างและราคาเริ่มต้น
- เลือกหอพักเพื่อเปรียบเทียบจำนวน 2–3 แห่ง
- แสดงรายละเอียดหอพักแบบ Side-by-Side
- แสดงค่าเช่า ค่าน้ำ/ค่าไฟ เงินประกัน สิ่งอำนวยความสะดวก
- กฎระเบียบ คะแนนรีวิว และระยะทางจากมหาวิทยาลัย
### Out of scope
- การสมัครสมาชิก / เข้าสู่ระบบ
- การลงทะเบียนหอพักของเจ้าของหอพัก
- การแก้ไขข้อมูลหอพักโดยเจ้าของหอพัก
- การอนุมัติข้อมูลหอพักโดย Admin
- การจองห้องพัก
- การชำระเงิน
- การจัดการรีวิว
## Constraints
- CON-TECH-01 ระบบต้องสามารถค้นหาและแสดงข้อมูลหอพักจากฐานข้อมูลกลาง
- DOM-DATA-01 ข้อมูลหอพักที่นำมาแสดงต้องเป็นข้อมูลที่ผ่านการอนุมัติและเผยแพร่แล้ว
- DOM-SEARCH-01 การค้นหาต้องรองรับเงื่อนไขหลายรายการพร้อมกัน
  เช่น งบประมาณ ระยะทาง สิ่งอำนวยความสะดวก และนโยบายเลี้ยงสัตว์
- DOM-COMPARE-01 ผู้ใช้สามารถเลือกหอพักเพื่อเปรียบเทียบได้สูงสุด 3 แห่ง
- DOM-RESP-01 ตารางเปรียบเทียบต้องรองรับ Responsive Design
  ทั้งบนสมาร์ตโฟนและคอมพิวเตอร์
## Requirements
- FR-DORM-01 ระบบต้องให้ผู้ใช้ระบุเงื่อนไขการค้นหา เช่น ช่วงราคา
  ระยะห่างจากสถานศึกษา สิ่งอำนวยความสะดวก และนโยบายเลี้ยงสัตว์
- FR-DORM-02 ระบบต้องแสดงเฉพาะหอพักที่มีข้อมูลตรงตามเงื่อนไขที่ผู้ใช้เลือก
- FR-DORM-03 ระบบต้องแสดงรายการหอพักที่ตรงตามเงื่อนไข
  พร้อมสถานะห้องว่างและราคาเริ่มต้น
- FR-DORM-04 เมื่อไม่พบหอพักที่ตรงตามเงื่อนไข ระบบต้องแจ้งเตือน
  และแสดงรายการหอพักแนะนำบริเวณใกล้เคียง หรือแนะนำให้ลดเงื่อนไขการค้นหา
- FR-DORM-05 ผู้ใช้สามารถเลือกหอพักที่สนใจเข้าสู่ Compare List ได้สูงสุด 3 แห่ง
- FR-DORM-06 หากผู้ใช้เลือกหอพักเกิน 3 แห่ง ระบบต้องแจ้งเตือน
  และไม่อนุญาตให้เพิ่มหอพักรายการที่ 4
- FR-DORM-07 ระบบต้องแสดงตารางเปรียบเทียบหอพักแบบ Side-by-Side
  โดยแสดงข้อมูลหลัก ได้แก่ ค่าเช่ารายเดือน ค่าน้ำ/ค่าไฟ ค่ามัดจำ
  สิ่งอำนวยความสะดวก และระยะทางจากมหาวิทยาลัย
- FR-DORM-08 ระบบต้องแสดงกฎระเบียบและคะแนนรีวิวของหอพักในตารางเปรียบเทียบ
- FR-DORM-09 หากเกิดข้อผิดพลาดในการเชื่อมต่อฐานข้อมูล ระบบต้องแจ้งเตือนผู้ใช้
  และไม่แสดงหน้าเว็บเปล่า
- FR-DORM-10 เมื่อเกิดข้อผิดพลาด ระบบต้องคงค่าตัวกรองเดิมไว้
  เพื่อให้ผู้ใช้สามารถปรับแต่งและค้นหาใหม่ได้
## Quality Requirements
- NFR-PERF-01 ระบบต้องแสดงผลลัพธ์การค้นหาและตารางเปรียบเทียบ
  ภายในเวลาไม่เกิน 2 วินาที ณ ปริมาณทราฟฟิกปกติ
- NFR-USE-01 ตารางเปรียบเทียบต้องแสดงข้อมูลอย่างชัดเจน
  และใช้งานได้ทั้งบนสมาร์ตโฟนและคอมพิวเตอร์
- NFR-AVA-01 ระบบค้นหาและฐานข้อมูลหอพักต้องมีความพร้อมใช้งาน
  (Uptime) ไม่น้อยกว่า 99.5%
## Acceptance Criteria
- [ ] AC-DORM-01 (FR-DORM-02)
      Given ผู้ใช้เลือกตัวกรองการค้นหา
      When  ผู้ใช้กดปุ่ม "ค้นหา"
      Then  ระบบต้องแสดงเฉพาะหอพักที่มีข้อมูลตรงกับทุกเงื่อนไขที่เลือก

- [ ] AC-DORM-02 (FR-DORM-03)
      Given มีหอพักที่ตรงตามเงื่อนไข
      When  ระบบค้นหาข้อมูลสำเร็จ
      Then  ระบบต้องแสดงรายการหอพัก พร้อมสถานะห้องว่างและราคาเริ่มต้น

- [ ] AC-DORM-03 (FR-DORM-04)
      Given ไม่มีหอพักที่ตรงตามเงื่อนไข
      When  ผู้ใช้ค้นหาหอพัก
      Then  ระบบต้องแจ้งว่า "ไม่พบหอพักที่ตรงกับเงื่อนไขที่ระบุ"
      และแสดงหอพักแนะนำบริเวณใกล้เคียงหรือแนะนำให้ลดเงื่อนไขการค้นหา

- [ ] AC-DORM-04 (FR-DORM-05)
      Given ผู้ใช้มีหอพักที่สนใจ
      When  ผู้ใช้เลือกหอพักเพื่อเปรียบเทียบ
      Then  ระบบต้องเพิ่มหอพักเข้าสู่ Compare List
      และสามารถเลือกได้สูงสุด 3 แห่ง

- [ ] AC-DORM-05 (FR-DORM-06)
      Given ผู้ใช้เลือกหอพักเพื่อเปรียบเทียบแล้ว 3 แห่ง
      When  ผู้ใช้เลือกหอพักแห่งที่ 4
      Then  ระบบต้องแจ้งเตือนและปฏิเสธการเพิ่มหอพักแห่งที่ 4

- [ ] AC-DORM-06 (FR-DORM-07)
      Given ผู้ใช้เลือกหอพักจำนวน 2–3 แห่ง
      When  ผู้ใช้กดปุ่ม "เปรียบเทียบหอพัก"
      Then  ระบบต้องแสดงตารางเปรียบเทียบแบบ Side-by-Side
      โดยมีค่าเช่ารายเดือน ค่าน้ำ/ค่าไฟ ค่ามัดจำ
      สิ่งอำนวยความสะดวก และระยะทางจากมหาวิทยาลัย

- [ ] AC-DORM-07 (FR-DORM-09)
      Given ระบบไม่สามารถเชื่อมต่อฐานข้อมูลได้
      When  ผู้ใช้ค้นหาหอพักหรือเปรียบเทียบหอพัก
      Then  ระบบต้องแสดงข้อความ
      "เกิดข้อผิดพลาดในการโหลดข้อมูล กรุณาลองใหม่อีกครั้งในภายหลัง"

- [ ] AC-DORM-08 (FR-DORM-10)
      Given เกิดข้อผิดพลาดในการค้นหา
      When  ระบบแสดงข้อความแจ้งเตือน
      Then  ระบบต้องคงค่าตัวกรองเดิมไว้
      เพื่อให้ผู้ใช้สามารถปรับแต่งและค้นหาใหม่ได้

- [ ] AC-DORM-09 (NFR-PERF-01)
      Given ระบบทำงานภายใต้ปริมาณทราฟฟิกปกติ
      When  ผู้ใช้ค้นหาหอพักหรือเปิดตารางเปรียบเทียบ
      Then  ระบบต้องแสดงผลภายในเวลาไม่เกิน 2 วินาที

- [ ] AC-DORM-10 (NFR-USE-01)
      Given ผู้ใช้เปิดหน้าตารางเปรียบเทียบ
      When  ผู้ใช้เข้าถึงระบบผ่านสมาร์ตโฟนหรือคอมพิวเตอร์
      Then  ตารางต้องแสดงผลอย่างชัดเจนและรองรับ Responsive Design

- [ ] AC-DORM-11 (NFR-AVA-01)
      Given ระบบค้นหาและฐานข้อมูลหอพักเปิดให้บริการ
      When  มีการใช้งานระบบ
      Then  ระบบต้องมี Uptime ไม่น้อยกว่า 99.5%
## Assumptions & Open Questions
- ASM-01 ข้อมูลหอพักที่แสดงในระบบเป็นข้อมูลที่ผ่านการอนุมัติจาก Admin แล้ว
- ASM-02 ระยะทางจากสถานศึกษาคำนวณจากตำแหน่งของหอพักและสถานศึกษาที่กำหนดไว้ในระบบ
- ASM-03 ราคา ค่าใช้จ่าย และสิ่งอำนวยความสะดวกของหอพักเป็นข้อมูลล่าสุด
  ที่เจ้าของหอพักหรือ Admin ได้บันทึกไว้
- ASM-04 ผู้ใช้ไม่จำเป็นต้อง Login เพื่อค้นหาและเปรียบเทียบหอพัก
- ASM-05 ผู้ใช้สามารถเปรียบเทียบหอพักได้จำนวน 2–3 แห่ง
- Q-01 หากหอพักมีข้อมูลบางฟิลด์ไม่ครบ ควรแสดงเป็น "ไม่มีข้อมูล"
  หรือไม่นำหอพักนั้นมาแสดง?
- Q-02 "หอพักบริเวณใกล้เคียง" ควรกำหนดระยะทางเพิ่มเติมจากเงื่อนไขเดิมเท่าใด?
- Q-03 คะแนนรีวิวควรคำนวณจากคะแนนเฉลี่ยทั้งหมด หรือใช้คะแนนจากช่วงเวลาที่กำหนด?
